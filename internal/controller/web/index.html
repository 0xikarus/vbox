Saved login profiles

Account-wide credentials, managed by owners. Select profiles above when creating a box; existing boxes are unchanged. Credentials are never displayed or downloaded.

Upload or refresh profiles through the CLI: vmbox profiles save APPLICATION NAME. Deleting a saved profile leaves credentials already copied into boxes untouched. Pending creations using it may fail.

Provider schema reference · JSON


Capacity
Each running box occupies one compute slot. Dedicated workers have one slot; shared workers host several slots on the same CPU and memory. New boxes use automatic placement; expand the placement override to compare worker pools. Hibernated boxes retain storage without occupying a slot.
Slot location
Choose the region for this provider’s fleet before provisioning slots. Changing location requires zero desired slots, zero actual slots, and no existing boxes. Existing slots and workspace volumes cannot be moved here. Do not delete workspaces just to change location.
Increasing capacity may incur provider charges. Reducing capacity drains free slots; occupied slots are not forcibly stopped.


Costs
Load accrued costs reported for the default provider’s fleet services in its current billing period. This does not start or contact boxes. Provider-wide charges that are not attributed to a fleet service may be absent.
